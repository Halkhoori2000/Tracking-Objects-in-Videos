Object Tracking in Videos

Tracks a moving car across video frames by finding where a bounding box from one frame best matches the next — using two algorithms: one for simple translation and a more sophisticated one that handles objects that rotate, scale, or shear as they move.

Extends LK to a full 6-parameter affine warp — handles rotation, scale, and shear. Precomputes the Jacobian and Hessian on the template once, making each frame update cheaper.

Algorithm Comparison

Lucas-Kanade — Forward Additive

Iteratively estimates the (u, v) translation that minimises the sum of squared intensity differences between the template patch and the warped current frame. Uses Gauss-Newton updates — each iteration recomputes the image gradients at the current warp.

% Given: template T, current frame I, bounding box Initialise: u = 0, v = 0 Repeat until |Δp| < ε: 1. Warp I → aligned coords: I_w(x) = I(x + [u,v]) 2. Image gradients: [Ix, Iy] at warped coords 3. Steepest descent: A = [Ix, Iy] 4. Gauss-Newton update: Δp = (AᵀA)⁻¹ Aᵀ (T − I_w) 5. Update warp: [u, v] += [Δu, Δv]
Parameters 2 (u, v translation)
Jacobian recomputed Every iteration
Handles Translation only

Matthews-Baker — Inverse Compositional

Extends tracking to a full 6-parameter affine warp. The key insight: move the expensive Jacobian and Hessian computation to the template, which never changes — so they are computed once at initialisation and reused every frame. Only the image warp is recomputed per frame.

% Precompute once on template T: J = ∇T · dW/dp % Jacobian, 6-param affine H⁻¹ = (JᵀJ)⁻¹ % Per frame (cheap): 1. Warp current image: I_w = I(W(x; p)) 2. Compute update: Δp = H⁻¹ Jᵀ (I_w − T) 3. Compose warp: W ← W · W(Δp)⁻¹
Parameters 6 (affine warp)
Jacobian recomputed Once (on template)
Handles Translation, rotation, scale, shear
Key difference: In standard LK, the warp update is additive (p ← p + Δp) so the Jacobian must be recomputed at the new warp each iteration. In the Matthews-Baker formulation, the update is compositional (W ← W · W(Δp)⁻¹) and evaluated at the identity, meaning the Jacobian only depends on the fixed template — making each tracking iteration significantly cheaper at the cost of a one-time precomputation.
